# Register Form

This is a simple registration form UI built using HTML and CSS. The form allows users to register by providing their username, email, and password.

## Installation

To use the registration form, simply download or clone the repository and open the `index.html` file in a web browser.

```
git clone https://github.com/anamika3012/Register-Form.git
cd register-form
open index.html
```

## Usage

The registration form has the following fields:

- **Username**: The user's desired username.
- **Email**: The user's email address.
- **Password**: The user's desired password.
- **Confirm Password**: The user's password confirmation.

To register, the user should fill out the form and click the "Register" button.
